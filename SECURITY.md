# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue or vulnerability in `unslop`, please do NOT open a public issue.

Please report security issues directly by emailing security@unslop.dev or opening a private disclosure report on GitHub.
All reports will receive an initial response within 48 hours.
